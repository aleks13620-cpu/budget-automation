# Ретро 11.09.2026 — Ф9: цена только с подтверждённым диаметром, материал для Ивана

**Что сделал.** Эталон 63 найденных цен (у Ивана верных 33 из 44 — четверть неверна). ISO/DIN/EN не марка,
строгая сверка диаметра в поиске, подпись слоя 1 = выгрузке (Ф1.1). Выложено на прод (`11b066c`), «Арта ОВ»
перепрогнана на проде: 43 цены, три ошибки диаметра исправлены. Материал для Ивана — по данным прода, 10 пометок ⚠.

**Что сработало.** Приёмка своим прогоном и глазами по скриншотам, а не по отчётам агентов: она нашла пять
вещей, которые пропустили исполнители, эталон и пять ходов — размер после косой черты (`VFM-2R/Dy32`), цену
за Ду15 со страниц серий, регрессию `1" 1/2` → Ду25, термометр Ø80 против d.100, шифр проекта как марку.

**Что не сработало.**
- Две слепые проверки висели 40 и 10+ минут на открытии сайтов продавцов, без срока — заметил, когда спросил CEO.
- Задание 9.3 без реальных строк целевых позиций → второй раунд; исполнитель 9.5а поменял поведение сверх
  задания → регрессия и второй раунд.
- Пометка «⚠» привязана к ссылке эталона: при смене карточки у той же неверной позиции пометка пропадает.
- Материал сначала собран по локальному прогону, а на проде живая выдача через 6 часов разошлась в 7 строках из 44.

**Методика — в этот проект, не в ai-clone:**
- Пометки качества в материале для клиента — по позиции, не по ссылке: неверная позиция остаётся неверной с любой карточкой.
- Материал клиенту строить из тех же данных, которые он увидит в системе, — из прода после прогона, не из локального замера.
- Задание исполнителю разбора — сразу с реальными строками, на которых сломано (`VFM-2R/Dy32/Kvs16`, `1" 1/2`).
- Марка — только артикул изделия: стандарт (ISO 7), класс защиты (IP54), шифр проекта (ОА-06-03-2024-ВК) — не марка.
