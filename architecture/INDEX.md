# Архитектура — индекс

Единая точка входа в архитектурное описание. Каждый раздел ниже — отдельный каталог с одним главным файлом.

## Маршрут «start here» (порядок чтения для нового человека)

1. [`README.md`](../README.md) — что делает приложение, стек, рабочий процесс оператора, API.
2. [`architecture/INDEX.md`](INDEX.md) — этот файл; карта 9 разделов.
3. [`docs/plans/active/PLAN_track_A_B_metric_gated_2026-06-11.md`](../docs/plans/active/PLAN_track_A_B_metric_gated_2026-06-11.md) — действующий стратегический план (Поток А «Доверие» + Поток Б «Обучение»), метрики, текущая фаза.
4. [`.business/INDEX.md`](../.business/INDEX.md) — бизнес-контекст (рынок, оператор, ценовая модель).
