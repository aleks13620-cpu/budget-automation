## Как вести процесс
1. **Серийно, по одной фазе.** Один независимый агент на фазу. Давай ему **самодостаточный бриф из плана** — он не помнит этих обсуждений.
2. **Ёмкость фазы ≤ 4 человеко-часа.** Если агент сообщает о превышении — **дроби фазу**, не дави.
3. **Гейт после каждой фазы:** проверяй «Готово» **как diff/факт, а не рассказ агента** (юнит-зелёный ≠ фича подключена; push ≠ deployed). Только потом следующая фаза.
4. **Каждый вывод — с доказательной базой** (код `file:line` / прод / прогон). Гипотезу маркируй и проверяй ПРЕЖДЕ чем утверждать. Метрики без эталона = шум.
5. **Завершай каждую итерацию разбора леджером БЕРУ/ИГНОРИРУЮ** (не аналитикой).
