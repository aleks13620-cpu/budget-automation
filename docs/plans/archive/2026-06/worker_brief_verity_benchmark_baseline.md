## Скоуп

### A. Многопроектный held-out бенчмарк (движок метрики, переиспользуемый)
Обобщи `scripts/verity-sokoliy-endtoend.mjs` в бенчмарк по нескольким эталонам. **Без утечки:** каталог НЕ должен содержать ответов тестируемого набора; ground-truth матчеру не виден.
Held-out наборы (на ТЕКУЩИХ данных):
1. **Сокольи (пр.1):** 28 пар по цене — чистый held-out (уже исключён из каталога).
2. **Ласточка (пр.11):** 150 операторских подтверждений как ground-truth (**оговорка: confirmed ≠ verity, но честный прокси**; домен ОВ ≠ ВК Сокольих) — исключён из каталога.
3. **Train/test split на исторических (Новая Самара / Совжи ВК,ОВ / Престиж):** для каждого — спрячь ДЕТЕРМИНИРОВАННУЮ долю пар (напр. каждую 4-ю по индексу — без random, чтобы воспроизводилось) из бутстрапа каталога, наполни каталог ОСТАЛЬНЫМ + другими проектами, тестируй на спрятанных. Это leakage-free кросс-проектный замер, выжимающий текущие данные максимально.
Для КАЖДОГО набора, на ВСЕХ измеримых парах (не только трудных), снять в ДВУХ режимах:
- **AI-ON** → верность@1/@3 (операторская метрика, что увидит оператор).
- **AI-OFF + каталог** → durable@1/@3 (стратегический капитал).
