# ФИКС-РАУНД 1 (после 5-move гейта оркестратора) — выполнять на ветке `feat/matcher-marking-discriminator`

## Блокер (главное)
Сейчас конфликт по «голому числу» (одиночный целый размер) **перебивает** совпадение по сильному признаку. Пример: `Труба Дн57х3,5 6000` vs `Труба Дн57х3,5 3000` → `-1`, хотя диаметр И сечение СОВПАДАЮТ (отличается лишь длина реза). Это занижает ВЕРНЫЙ матч. Корень: в `getStructuralScore` любой конфликт (включая слабые `sizes`) делает `return -1`, уравнивая длину реза с диаметром.

## Продуктовое правило владельца (соблюсти ТОЧНО, 2026-06-05)
Числа — **НЕ всегда** «лишние»:
- **Габариты товара — это идентичность.** У радиатора «3600 на 1200» (и одиночная высота «500») цифры — это сам товар: другие цифры = ДРУГОЙ товар → различать.
- **Буквенные маркировки (CV/CVL = право/лево) — всегда значимы** → различать.
- **НО** несущественное число (длина отрезка трубы, длина бухты кабеля) **НЕ должно «убивать» матч**, если диаметр/сечение/маркировка уже совпали.

## Принцип фикса (НЕ «выкинуть числа», а понизить их вес)
Сделай «голые размеры» **слабым** сигналом, а не вето:
1. Конфликт по СИЛЬНОМУ признаку (DN / сечение AxB / конфиг тройника / буквенная марка) → `-1` (другой товар) — СОХРАНИТЬ.
2. **Если по сильному признаку СОГЛАСИЕ — конфликт по голому числу его НЕ перебивает** (длина реза не отменяет совпадение трубы).
3. Если СИЛЬНОГО признака нет вообще — голое число всё ещё различает (радиатор по одной высоте «500» vs «600» → `-1`).
4. **Габаритные ПАРЫ = сечение (сильный признак), независимо от разделителя:** «3600x1200», «3600х1200», «3600 на 1200», «3600*1200» → одна сущность cross (упорядоченная, точная). Тогда разные габариты радиатора корректно конфликтуют, а общая одна сторона не даёт ложного «совпало».

## Мелочи из гейта (тоже починить)
- **Десятичная запятая:** нормализуй «57,5»→«57.5» ДО извлечения DN, чтобы хвост «,0/,5» не утекал отдельным «размером» (`Дн108,0` сейчас даёт лишний размер `0`).
- **Артикульные коды:** не считай очевидные свободные каталожные коды размерами (фабрикуют ложный конфликт). Пини поведение тестами ниже.

## Red-first тесты ДОБАВИТЬ (падают до фикса, зелёные после) + все 25 прежних ОСТАЮТСЯ зелёными
- труба: `Дн57х3,5 6000` vs `Дн57х3,5 3000` → НЕ штраф (совпало сечение; длина несущественна);
- кабель: `Кабель 3х2,5 бухта 100` vs `…200` → НЕ штраф;
- радиатор-пара: `Радиатор 3600 на 1200` vs `3000 на 1200` → РАЗНЫЕ (пара = сечение);
- радиатор-высота: `Радиатор 500` vs `600` → РАЗНЫЕ (голое число решает, сильного признака нет);
- десятичный: `Дн108,0` → DN=108 без лишнего размера; `Дн57,5` vs `Дн57,8` → НЕ ложный конфликт;
- маркировка не сломана: `CV` vs `CVL` → РАЗНЫЕ (как было).
