## Зачем (главный стратегический вопрос проекта)
Фаза-2 дала **42.9%** durable AI-OFF — НО в ИДЕАЛИЗИРОВАННОМ замере: каталог наполнялся **ЖИВЫМ ПУЛОМ счетов того же проекта** (`recordPair(p.name,null)` по пулу) → для каждого аналога гарантированно был паспорт → число ≈ структурное согласие spec↔аналог (`getStructuralScore==1` у 13/28), **а НЕ кросс-проектная память**.
**Главная ставка стратегии:** каталог как ПЕРЕНОСИМОЕ знание — помогает ли знание из ПРОШЛЫХ проектов узнавать товары на НОВОМ (held-out) проекте без ИИ. Этот замер отвечает честно.

- **≈42.9%** → перенос работает, кросс-проектная память реальна → ставка подтверждена в прод-условиях.
