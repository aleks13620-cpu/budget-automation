### Сразу учесть четыре правки из критики Ивана (Фаза 2 плана)

4. **Приоритет знакомым поставщикам,** чёрный список мёртвых сайтов (проконсим — «помер,

## Грабли этого проекта — на них уже наступали

**Сводную цифру не называть, пока не разобраны выбросы.** За два дня цифра трижды
менялась в полтора-два раза: «80%» оказалось 52%, «45%» оказалось 85%. Каждый раз причина
была в отборе, а не в поиске. Порядок: посчитать → открыть крайние → проверить 5–8
попаданий по названию карточки, а не по URL → искать системную причину у промахов.

**Типоразмер — не марка.** `DN20`, `Ду25`, `Ру40`, `Tmax180`, `G1/2` в качестве марки
уводят поиск на любой товар того же диаметра. Детектор это уже отсекает — не сломать.

**Марка лежит в разных полях** у разных парсеров: `product_code`, `characteristics`,
`manufacturer`, прямо в `name`. Искать по признаку, а не по имени поля.

**Search API иногда отдаёт HTTP 499** («cancelled received from server») — одиночный
обрыв, лечится повтором, а не паузой. В коде уже три попытки.

**Клиенту не описывать как факт то, что собрано по частям.** В документе для Ивана
однажды стояло «стало» про несуществующую функцию — поймали до отправки.
