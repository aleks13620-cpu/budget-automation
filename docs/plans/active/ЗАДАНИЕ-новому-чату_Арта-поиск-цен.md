## РЕШЕНИЕ ПО ОБЪЁМУ ФАЗЫ 1 (принято 24.08, не переигрывать)

**Прогоняем как есть + одна правка вывода. Четыре правки Ивана — следующим заходом.**

### Почему не вшиваем их сразу

Проверено по данным прогона: **позиция, которую Иван раскритиковал, в этом слое не
встретится.** Кран за 401 ₽ — это «Кран под манометр трёхходовой G1/2/Py40/Tmax150»,
марки у него нет, детектор отправил его в слой «описаны словами».

Три правки из четырёх (критичные параметры по группам, чистка запроса, порядок вывода
вариантов) применяются именно к слою без марки — здесь их не на что применять: сверка
идёт по марке символ в символ. Четвёртая, чёрный список, тоже почти не срабатывает —
мёртвых сайтов среди продавцов слоя нет, проконсима там не оказалось.

Вшивать их сейчас — день-полтора работы, которая не изменит результат этого прогона,
пока Иван ждёт.

### Единственная правка, которую делаем сразу — вывод всех цен

```
46 позиций с ценой, из них 39 найдены у 2+ продавцов
среднее 3,9 продавца на позицию
```

Сейчас берётся минимальная цена молча. Это попадает ровно в тревогу Ивана: «цена висит
в интернете, который никто десять лет не менял, а в наличии его нет уже пять».

**Что делать:** в выгрузке по каждой позиции показать ВСЕ найденные цены с продавцами
и ссылками, по возрастанию. Данные уже собираются в `zamer_sloj_marka.py` (список `hits`),
просто не выгружаются — работы примерно полчаса.

Побочная польза: Иван, увидев разброс, сам назовёт сайты, которые не показывать. Это его
же просьба про «ограничитель», собранная с первого прогона, без наших догадок.

## Грабли этого проекта — на них уже наступали

**Сводную цифру не называть, пока не разобраны выбросы.** За два дня цифра трижды
менялась в полтора-два раза: «80%» оказалось 52%, «45%» оказалось 85%. Каждый раз причина
была в отборе, а не в поиске. Порядок: посчитать → открыть крайние → проверить 5–8
попаданий по названию карточки, а не по URL → искать системную причину у промахов.

**Типоразмер — не марка.** `DN20`, `Ду25`, `Ру40`, `Tmax180`, `G1/2` в качестве марки
уводят поиск на любой товар того же диаметра. Детектор это уже отсекает — не сломать.

**Марка лежит в разных полях** у разных парсеров: `product_code`, `characteristics`,
`manufacturer`, прямо в `name`. Искать по признаку, а не по имени поля.

**Search API иногда отдаёт HTTP 499** («cancelled received from server») — одиночный
обрыв, лечится повтором, а не паузой. В коде уже три попытки.

**Клиенту не описывать как факт то, что собрано по частям.** В документе для Ивана
однажды стояло «стало» про несуществующую функцию — поймали до отправки.
