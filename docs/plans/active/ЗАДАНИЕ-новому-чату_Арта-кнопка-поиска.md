## Почему нельзя просто положить скрипт на сервер — четыре причины

Проверено, не гипотезы:

1. **Dockerfile папку `price-harvester/` не копирует вообще.** В образ едут только
   `frontend/`, `backend/`, `scripts/`.
2. **В контейнере нет Python** — образ `node:20-alpine`.
3. **Ключ Yandex Search API на сервер не едет.** Лежит в `price-harvester/secrets/`,
   папка в `.gitignore` — и правильно, репозиторий публичный.
4. **Сервер ходит в интернет с адреса дата-центра**, а часть сайтов такие адреса
   блокирует. Это записано ещё в июне в `price-harvester/src/export_html.py`: сбор
   идёт с рабочей машины именно поэтому. На сервере часть источников закроется.

## Грабли, на которые уже наступали

**Конфиг деплоя читать из прод-ветки**, а не из рабочей копии: `git show origin/main:путь`.
Я на этом ошибся — сказал CEO «пуш задеплоит», а в проде стоял ручной запуск.

**200 ничего не доказывает.** Бэкенд отдаёт SPA-подмену на любой несуществующий адрес.
Сверять содержимое: заголовок страницы, число колонок, а лучше побайтно с эталоном.

**Ширину колонок Excel проверять числом.** Рендер в картинку переносит текст по словам,
а Excel обрезает, если справа непустая ячейка. Из-за этого предупреждение «проверьте»
не читалось ни в одной строке, и заметили это только на третьем проходе.

**После правки SQL внутри шаблонной строки — выполнить запрос.** Сборка TypeScript
не проверяет SQL: у меня выпало слово `WITH`, сборка была зелёная, запрос сломан.

**Предохранитель, который дороже угрозы, — не предохранитель.** Сверка по `project_id`
защищала от неверной заливки и при пустом значении молча обнуляла всю выгрузку.

**Смотреть выгрузку глазами обязательно.** Код был верный, а в документе стояло
«Ориг.» на интернет-цене и дублировалась «Цена с НДС» — обе неправды нашлись только
при осмотре файла.
