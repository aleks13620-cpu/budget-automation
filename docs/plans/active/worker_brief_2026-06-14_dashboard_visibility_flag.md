## 1. Цель (простыми словами)
У каждого проекта появляется галочка «показывать на главных показателях». Дашборд показывает только отмеченные. На странице у каждого проекта — кнопка «Скрыть»/«Показать», чтобы владелец сам разово убрал тестовые проекты. Никаких удалений данных, никаких жёстко прописанных списков id.

## 2. Ветка
Работай на ветке от текущего прода:
```
git fetch origin main
git checkout -b feat/dashboard-visibility origin/main
```
(origin/main сейчас = `fd57f63` — уже содержит дашборд v1.)

## 3. Что построить

### 3.1 Колонка в БД (миграция, идемпотентная)
Добавь к таблице `projects` колонку `show_on_dashboard INTEGER NOT NULL DEFAULT 1`.
- **Найди, как в проекте применяются миграции/схема** (поищи `ALTER TABLE`, `CREATE TABLE projects`, миграционный механизм в `backend/src/database*` или `backend/src/db`). Следуй существующему паттерну.
- Миграция должна быть **идемпотентной**: проверь через `PRAGMA table_info(projects)`, есть ли колонка; добавляй только если нет. Применяется при старте сервера.
- `DEFAULT 1` — значит после деплоя ВСЕ проекты по-прежнему видны (ничего не пропадёт внезапно); владелец сам скроет тестовые кнопкой.

### 3.2 Эндпоинт-переключатель (новая мутация)
`POST /api/projects/:id/dashboard-visibility` body `{ "show": true|false }`:
- Валидирует `id` (число, проект существует) и `show` (boolean).
- `UPDATE projects SET show_on_dashboard = ? WHERE id = ?` (параметризованно).
- Сбрасывает кэш дашборда (есть `_invalidateDashboardCacheForTests` в `metricsDashboard.ts` — экспортируй нормальную `invalidateDashboardCache()` и вызови; либо просто обнули модульный кэш). Чтобы изменение было видно сразу, а не через минуту.
- Возвращает `{ id, show_on_dashboard }`.

### 3.3 Фильтр дашборда — заменить хрупкую эвристику на флаг
В `metricsDashboard.ts` сейчас фильтр: `spec_total > 100 AND (with_any_candidate > 0 OR confirmed > 50)`. **Замени** на:
```
WHERE show_on_dashboard = 1 AND spec_total > 0
```
То есть: показываем проект, если он помечен «показывать» И в нём есть хоть одна строка сметы (отсекает пустышку пр.1 «Сокольи горы» с 0 строк). Логику top-1/coverage НЕ трогай — она верная.

### 3.4 Фронт — кнопка у каждого проекта
В `MainMetrics.tsx` у каждой строки-проекта добавь кнопку:
- Текст «Скрыть» (если сейчас показывается). По клику — POST `dashboard-visibility {show:false}`, потом перезагрузка списка.
- Поскольку дашборд показывает только видимые, скрытый проект исчезнет из списка после клика. Чтобы можно было ВЕРНУТЬ — добавь в шапке маленький переключатель «Показать скрытые» (чекбокс). Когда включён — запрашивай дашборд с `?includeHidden=1`, эндпоинт тогда вернёт и скрытые (с пометкой «скрыт») и у них будет кнопка «Показать».
- Простыми словами, без жаргона.

### 3.5 Эндпоинт — поддержать includeHidden
`GET /api/metrics/dashboard?includeHidden=1` — вернуть все проекты с `spec_total > 0` (и скрытые тоже), добавив в ответ поле `show_on_dashboard`. Без параметра — только видимые (как 3.3).
