## Почему это тавтология (подвох в данных)

Дополнительная проверка структуры `matches[]` для каждого spec_item:

| категория spec_item | штук | длина matches[] (avg / min / max) |
| --- | --- | --- |
| confirmed (есть хоть один confirmed match) | 268 | **1.00 / 1 / 1** |
| matched_no_conf (матчи есть, confirmed нет) | 65 | 3.11 / 1 / 8 |
| unmatched | 44 | 0 / 0 / 0 |

**У ВСЕХ 268 confirmed-spec в `matches[]` ровно ОДИН элемент** — сам подтверждённый матч. Альтернативные кандидаты, которые система когда-то предлагала, в API НЕ возвращаются.

Следствие: «top-1 по confidence» вырождается в «единственный элемент», и top-1 == GT всегда — by construction. Это не «система угадывает», это «API не показывает соперников».

Сравни с категорией `matched_no_conf` (65 spec) — там среднее 3.11 кандидата на spec, до 8. То есть rivals существуют, но скрываются после confirm.
