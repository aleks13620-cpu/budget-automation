## 0. ДИСЦИПЛИНА (анти-дрейф — ГЛАВНОЕ правило)
- **Веду по МЕТРИКЕ, не по списку задач.** Каждый шаг докладывается как дельта метрики: было → стало.
- **ПЕРЕД стройкой — доказать дёшево** (офлайн-замер / сценарий), что рычаг двигает метрику. *(Это спасло 3 ненужные стройки 06-11: парсер, дословные правила, эмбеддинги.)*
- **ПОСЛЕ — замерить. Метрика растёт → продолжаем тем же. Метрика стоит/падает → СТОП + рефлексия + смена рычага.** Нет «висящих» полу-фаз. Отрицательный результат фиксируется в память и меняет план.
- **Не сползать в детали:** детали — воркеру; в ответе владельцу — метрика + «до/после» простым языком, без сокращений.

## 1. ЦЕЛЬ И ГЛАВНАЯ МЕТРИКА
- **Цель:** оператор ДОВЕРЯЕТ системе → продукт продаётся.
- **Главная метрика: Точность@1 на матчимом ≥ 80%.** (Сейчас пр.12 = 78.6% — близко.)

## 2. ГЛОССАРИЙ (фиксируем — используем везде, БЕЗ старых сокращений)
| Термин | Что это (простыми словами) |
|---|---|
| **Точность@1** | % матчимых позиций, где система с ПЕРВОЙ попытки даёт ПРАВИЛЬНЫЙ аналог (мерять по Эталону) |
| **Матчимое** | позиции, которые в принципе можно свести (исключая структурное — изготовление на заказ, напр. воздуховоды) |
| **ИИ (Учитель)** | большая языковая модель; читает новое по смыслу, предлагает аналог. Умный, но платный/не мгновенный |
| **Память** | таблица «правила сопоставления» (`matching_rules`) + словарь синонимов. ОБЩАЯ на все проекты, ПОСТОЯННАЯ. Хранит подтверждённые Связки |
| **Связка** | подтверждённая пара «позиция сметы → правильный аналог в счёте» |
| **Эталон** | ручной финальный результат владельца = правда (ground truth), по нему мерим Точность@1 |
| **Доля памяти** | % матчей, сведённых из Памяти БЕЗ ИИ (мера наполнения/обучения) |
| **Умный слой** | будущий семантический слой (понимает смысл слов без ИИ — эмбеддинги/каталог). ПОЗЖЕ |
> ОТМЕНЕНЫ как путающие: «РОВ» → говорим **Память**; «durable» → **Доля памяти / без ИИ**; «verity@1» → **Точность@1**.

## 3. МЕТРИКИ (что меряем · цель · текущее)
**ГЛАВНАЯ**
- **Точность@1 на матчимом** — цель ≥80% — *пр.12 = 78.6%*. Мерять по Эталону.

**ПОТОК Б — Память / Обучение**
- **Доля памяти** = % матчей из Памяти без ИИ — РАСТЁТ = обучение работает — *пр.6=14%, пр.11=38%, пр.12=0%*. Цель: зрелый проект ≥40%, новые растут от 0.
- **Размер памяти** = число правил + синонимов (ведущий индикатор, растёт от Связок).

**ПОТОК А — Доверие**
- **Ложно-уверенные** = число уверенных матчей, оказавшихся неверными (по Эталону/жалобам) — ПАДАЕТ.
- **Трение оператора** = правок/отклонений на проект — ПАДАЕТ.

**УМНЫЙ СЛОЙ (позже)**
- **Обобщение** = % НОВЫХ формулировок (не точных повторов), сведённых Памятью без ИИ — *сейчас ≈0*. Это и есть метрика «слоя».
